# 🎮 Rock Paper Scissors Game

A fun and interactive Rock Paper Scissors game built using **HTML, CSS, and JavaScript**. Players can compete against the computer, which makes random choices, and the scores are updated dynamically after each round.

## 📸 Preview

Simple and responsive UI featuring:
- Rock ✊
- Paper ✋
- Scissors ✌️
- Live score tracking
- Computer-generated moves
- Instant result display

## 🚀 Features

✅ Interactive game interface

✅ Random computer moves

✅ Real-time score updates

✅ Win, Lose, and Draw detection

✅ Responsive design

✅ Beginner-friendly JavaScript project

## 🎯 Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choices result in a Draw

## ▶️ How to Run

1. Download or clone the repository.

```bash
git clone https://github.com/your-username/rock-paper-scissors.git
```

2. Open the project folder.

3. Run `index.html` in your browser.

4. Click on Rock, Paper, or Scissors to play.
